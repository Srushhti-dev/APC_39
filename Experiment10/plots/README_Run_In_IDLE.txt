MATPLOTLIB PLOT PROGRAMS - HOW TO RUN IN IDLE

1. Extract this ZIP file to a folder.
2. Open Python IDLE.
3. Click File > Open and choose any .py program.
4. In the editor, press F5 or choose Run > Run Module.
5. A graph window should appear.

If you see "No module named matplotlib":
1. Open Command Prompt (CMD).
2. Run: py -m pip install matplotlib
3. Restart IDLE and press F5 again.
